KING'S CUT WEBSITE DEMO
Files:
- index.html
- style.css
- script.js

Preview locally:
1. Keep all three files in the same folder.
2. Double-click index.html to open it in your browser.

Publish:
- Upload all three files to Netlify Drop, or push them to a GitHub repository and enable GitHub Pages.

Important before presenting as a final live website:
- Confirm the business hours and services directly with the owner.
- Replace the stylized gallery artwork with the shop's real photos (with permission).
- Confirm the phone number and address.
- Ask whether the shop wants online appointment booking; this demo currently uses click-to-call.
- This is an independent demo concept, not an official King's Cut website.
